## Problem

zwo next --line inbox-triage returns only tickets labeled line:inbox-triage, and on 2026-10-16 none of the 147 open dotfiles tickets carries a label, so the line queue would read empty and the orchestrator would seat nothing.

## Owner words

> automate the fuck out of shit (item 30)

> low degree of freedom with scripts and checkl;ist and makefiles (item 30)

## Context

Order ORD-0932-next Q2: Every build-order ticket gets its line label by script. The orchestrator seats from zwo next --line inbox-triage. 2026-08 Venture 1 business tickets stay untouched (not cancelled); the line label keeps them out of the queue (Q3).

Fact 2026-10-16: the open dotfiles tickets hang under five roots, all line work: WO-20261016-0272 - Inbox-triage line build order - DAG of line nodes, WO-20261016-1703 - Inbox sweep build, WO-20261016-3570 - Stuck-watch: no-model stuck detection to the bus and the owner phone, with a deadman, WO-20261016-3610 - merge-train batch promotion: dev, UAT, stable per batch on a cadence, WO-20261016-ebe4 - One PR process for every repository, ported from coq. New children inherit the parent labels (WO-20261016-67c7), so this run is once. A root added later passes --label line:inbox-triage at new. Business build-order tickets (yp-home, yp-wiki, yp-wire, content engine) are labeled by a business design seat with the same verb; Venture 1 tickets are never labeled.

## Scope

**In**

- touches (generated by work-order.sh set only, never by hand): every non-archived work-orders/**/WO-*.md file gains the labels key; work-orders/INDEX.md and epic README.md are ignored generated views, never git add
- step: branch from origin/main in your own worktree after WO-20261016-67c7 merged
- step: run `bash claude/skills/work-order/scripts/work-order.sh set --project . --tree WO-20261016-0272 --add-label line:inbox-triage` and the same command with --tree WO-20261016-1703, WO-20261016-3570, WO-20261016-3610 and WO-20261016-ebe4
- step: run the AC checks; git add work-orders (never INDEX.md or a README.md); commit chore(work-orders): label open tickets line:inbox-triage (ORD-0932 Q2) with the ticket id; no Bump trailer
- tool: path:claude/skills/work-order/scripts/work-order.sh set (from WO-20261016-67c7, on main first) - fallback: set missing on main: stop with DESIGN-GAP; any set call fails: rerun it, it is idempotent, 3 times, then A2A-003 with its output
- tool: cmd:git, cmd:jq, cmd:gh - fallback: missing on the host: stop with ENV-MISSING; gh down at PR time: FB-003, push with git and park the PR step with a note

**Out - non-goals**

- business tickets: a business design seat runs the same verb there
- archived tickets: set --tree skips them by design
- any edit to a ticket other than the labels key; any file outside work-orders/: stop with DESIGN-GAP
- waiting on CI or merging: push, open the PR, write the result, leave (ORD-0542 O2)
